# RGDNS — Rcan Games Domain System

RGDNS is an experimental DNS prototype and Rcan Games website repository. The intended `.rg` namespace cannot become globally resolvable through this repository alone; public top-level-domain use requires registry arrangements and root-zone delegation.

## Website
The `index.html` file is the Rcan Games bilingual landing page. Enable GitHub Pages in Settings → Pages → Deploy from a branch → main → /(root).

## Prototype
A local authoritative DNS server prototype is provided for testing only. Sample IPs in `192.0.2.0/24` are documentation addresses, not production endpoints.
